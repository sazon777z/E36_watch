# BMW E36 On-Board Computer & Clock (ESP32-S3 + GMT024-08 ST7789)

Проект стилизованных цифровых часов и бортового компьютера в штатное место консоли BMW E36 (1991) с аутентичным янтарным стилем подсветки **BMW Amber**, поддержкой замера бортсети, секундомера M-Performance, автосинхронизации времени по Wi-Fi NTP и управления со смартфона.

---

## 1. Аппаратная часть (Распиновка подключения)

### Дисплей GMT024-08 (ST7789 SPI TFT 2.4" 240x320) к ESP32-S3:

| Пин дисплея | Пин ESP32-S3 | Назначение |
|---|---|---|
| **VCC** | 3.3V | Питание дисплея |
| **GND** | GND | Земля |
| **SCL** | **GPIO 13** | SPI Clock (SCK) |
| **SDA** | **GPIO 12** | SPI Data / MOSI |
| **RES / RST** | **GPIO 11** | Сброс дисплея |
| **DC** | **GPIO 10** | Выбор Режим/Команда |
| **CS** | **GPIO 9** | Chip Select |
| **BLK / BL** | **GPIO 8** | Подсветка (ШИМ регулировка яркости) |

### Дополнительные подключения (входы в авто):
* **GPIO 7 (ADC):** Вход вольтметра АКБ 12V через делитель напряжения (R1 = 30 кОм, R2 = 7.5 кОм).
* **GPIO 14:** Физическая кнопка переключения экранов (замыкание на GND).
* **GPIO 16:** Вход сигнала габаритов/фар (12V через оптопару или делитель к 3.3V) для ночного авто-диммирования.

## 2. Инструкция по сборке в Arduino IDE

### Шаг 1: Установка библиотек
В Arduino IDE перейдите в меню **Скетч $\rightarrow$ Подключить библиотеку $\rightarrow$ Управлять библиотеками...** и установите:
1. **`Adafruit GFX Library`** (от Adafruit)
2. **`Adafruit ST7789 and ST7735 Library`** (от Adafruit)
*(При предложении установить зависимые библиотеки нажмите "Install All")*

### Шаг 2: Настройки платы в Arduino IDE
В меню **Инструменты (Tools)** выберите:
- **Плата (Board):** `ESP32S3 Dev Module`
- **USB CDC On Boot:** `Enabled` (если используете прямой USB порт ESP32-S3)
- **Flash Size:** `4MB` (или `8MB`/`16MB` в зависимости от модуля)
- **Partition Scheme:** `Default 4MB with spiffs`

### Шаг 3: Загрузка
Откройте файл `E36_watch.ino` и нажмите кнопку **Загрузка (Upload)**.

## 3. Режимы работы и экраны (UI)

1. **Заставка при включении (Boot Splash):**
   - Круглый логотип BMW Bavaria, триколор ///M и плавный розжиг подсветки через ШИМ.
2. **Штатные часы E36 (Classic Clock & Date):**
   - Крупные цифры в янтарном цвете (BMW Amber) с теневыми неактивными сегментами как на оригинальном ЖК-дисплее BMW OBC.
   - Мигающее двоеточие, дата, день недели, напряжение АКБ и температура.
3. **Телеметрия и монитор генератора (OBC Telemetry):**
   - Точный вольтметр с динамической шкалой и фиксацией просадки при пуске стартера.
   - Время в пути (Trip Timer) и статусы заряда.
4. **Спортивный экран ///M Performance:**
   - Секундомер / замер времени с точностью до 0.1 сек (управление кнопкой: клик — старт/стоп, удержание — сброс).
5. **Инфо и настройки Wi-Fi:**
   - Отображение статуса системы, свободной памяти и параметров точки доступа.

## 4. Веб-интерфейс со смартфона

При включении ESP32-S3 создает собственную сеть Wi-Fi:
- **Имя сети (SSID):** `BMW_E36_OBC`
- **Пароль:** `12345678`
- **Адрес страницы настроек:** `http://192.168.4.1`

В веб-панели можно:
- Подключить БК к раздаче интернета с телефона для **автосинхронизации точного времени по NTP** и выбора часового пояса.
- Вручную выставить время и дату.
- Отрегулировать ползунком яркость подсветки дисплея в реальном времени.
- Переключить экран.
