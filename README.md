# BMW E36 On-Board Computer & Cockpit Gauge (ESP32-S3 + GMT024-08 ST7789)

Проект цифровых часов, бортового компьютера и спортивного кругового прибора в штатное место центральной консоли BMW E36 (1991). Построен на базе **ESP32-S3** и графической библиотеки **LVGL 8.3**, с прямой интеграцией по CAN-шине с ЭБУ **MegaSquirt 2**, GPS-модулем **u-blox NEO-7M**, настраиваемой системой аварийных предупреждений (варнингов) и управлением через кроссплатформенное Web Bluetooth приложение (**PWA**).

---

## 1. Аппаратная часть (Распиновка подключения)

### Дисплей GMT024-08 (ST7789 SPI TFT 2.4" 240x320) к ESP32-S3:

| Пин дисплея | Пин ESP32-S3 | Назначение |
|---|---|---|
| **VCC** | 3.3V | Питание дисплея |
| **GND** | GND | Земля |
| **SCL** | **GPIO 13** | SPI Clock (SCK) |
| **SDA** | **GPIO 12** | SPI Data / MOSI |
| **RES / RST** | **GPIO 11** | Сброс дисплея |
| **DC** | **GPIO 10** | Выбор Режим/Команда |
| **CS** | **GPIO 9** | Chip Select |
| **BLK / BL** | **GPIO 8** | Подсветка (вкл/выкл, всегда 100% яркость, регулировки нет) |

### CAN-трансивер WCMCU-230 (SN65HVD230) к MegaSquirt 2:

| Пин трансивера | Пин ESP32-S3 / Авто | Описание |
|---|---|---|
| **3V3** | **3.3V** | Питание логики трансивера от шины 3.3V |
| **GND** | **GND** | Общий провод (земля) |
| **CTX** | **GPIO 6** | Вход данных CAN (TWAI TX) |
| **CRX** | **GPIO 7** | Выход данных CAN (TWAI RX) |
| **CANH** | К проводу **CAN_H** | Шина данных к блоку MegaSquirt 2 |
| **CANL** | К проводу **CAN_L** | Шина данных к блоку MegaSquirt 2 |

> [!IMPORTANT]
> Линии данных подключаются **напрямую**, а не крест-накрест (**CTX -> GPIO 6**, **CRX -> GPIO 7**).

### GPS-модуль u-blox NEO-7M к ESP32-S3:

| Пин NEO-7M | Пин ESP32-S3 | Описание |
|---|---|---|
| **VCC** | **3.3V** или **5V** | Питание модуля |
| **GND** | **GND** | Общая земля |
| **TX** | **GPIO 44 (RX)** | Выход NMEA данных GPS в ESP32 |
| **RX** | **GPIO 43 (TX)** | Вход команд GPS из ESP32 |

### Дополнительные подключения:
* **GPIO 14:** Физическая кнопка переключения (клик - смена экрана; двойной клик - переключение датчика прибора; удержание - сброс суточного одометра).
* **GPIO 0:** Встроенная кнопка BOOT на плате ESP32-S3 (дублирует внешнюю кнопку для стендовых тестов).

## 2. Настройка в программе TunerStudio (MegaSquirt 2)

Чтобы ЭБУ отдавал данные в приборную панель по CAN-шине:
1. Откройте проект в **TunerStudio MS**.
2. Перейдите в меню **CAN-bus / Testmodes -> CAN Parameters**:
   - **Master Enable:** установите в **Enable (On)**.
3. Перейдите в меню **CAN-bus / Testmodes -> Dash Broadcasting** (или *CAN Realtime Data Broadcasting*):
   - **Enable:** установите в **On**.
   - **Baud Rate:** **500k** (500 kbit/s).
   - **Configuration:** **Automatic** (базовый ID 1512/1520).
4. Нажмите кнопку **Burn** для сохранения в память ЭБУ.

## 3. Инструкция по сборке в Arduino IDE

### Шаг 1: Установка библиотек
В Arduino IDE перейдите в меню **Скетч -> Подключить библиотеку -> Управлять библиотеками...** и установите:
1. **`lvgl`** (версия **8.3.11** от LVGL)
2. **`Adafruit GFX Library`** (от Adafruit)
3. **`Adafruit ST7789 and ST7735 Library`** (от Adafruit)
*(При предложении установить зависимые библиотеки нажмите "Install All")*

Скопируйте `extras/lv_conf.h` в папку библиотек (`Документы\Arduino\libraries\lv_conf.h`, рядом с папкой `lvgl`). Важно: в нем включен `LV_SPRINTF_USE_FLOAT 1` — без этого вместо дробных чисел на экране будет буква `f`.

### Шаг 2: Настройки платы в Arduino IDE
В меню **Инструменты (Tools)** выберите:
- **Плата (Board):** `ESP32S3 Dev Module`
- **USB CDC On Boot:** `Enabled`
- **Flash Size:** `4MB` (или `8MB`/`16MB`)
- **Partition Scheme:** `Default 4MB with spiffs`
- **PSRAM:** `Disabled` (прошивка не использует PSRAM; на текущей плате ее нет)

### Шаг 3: Загрузка
Откройте файл `E36_watch.ino` и нажмите кнопку **Загрузка (Upload)**.

## 4. Режимы работы и экраны (UI)

1. **Экран 1: Часы и приборы (Classic Clock & Cards):**
   - Компактные часы сверху (Montserrat 36).
   - 3 увеличенные спортивные плитки высотой 164 px во всю нижнюю часть экрана:
     - **`BOOST`** (чистые крупные цифры, подпись `bar`, при передуве мигает `OVERBOOST!`).
     - **`COOLANT`** (чистые цифры температуры ОЖ, подпись `°C`, при перегреве мигает `OVERHEAT!`).
     - **`AFR`** (чистые цифры смеси, снизу пусто, при аварийной смеси мигает `LEAN!` или `RICH!`).
2. **Экран 2: Бортовой компьютер и расход (OBC Trip & Fuel):**
   - GPS скорость и мгновенный расход (L/100km или L/H).
   - 3 плитки: пробег поездки (`TRIP DIST` со сбросом по удержанию), средний расход (`AVG CONS`) и расход в литрах (`TRIP FUEL`).
3. **Экран 3: Телеметрия мотора (OBC Telemetry):**
   - Напряжение АКБ и статус зарядки/просадки при пуске.
   - Температуры ОЖ и впускного воздуха IAT.
   - Состав смеси AFR и дроссель TPS / давление MAP.
   - Нижняя полоса наддува.
4. **Экран 4: Спортивный тахометр ///M Performance:**
   - Крупные обороты мотора (`RPM`), прогрессивный Shift-Light бар, давление наддува и УОЗ.
5. **Экран 5: Полноэкранный круговой прибор со стрелкой (Single Gauge):**
   - Аналоговая шкала 270° со стрелкой ///M Red и цифровым значением.
   - Выбор из 7 датчиков: `BOOST`, `COOLANT`, `AFR`, `INST_FUEL`, `SPEED`, `INTAKE_TEMP`, `RPM`.
   - Переключение датчика удержанием кнопки или через мобильное приложение.
   - Сохранение выбранного датчика в энергонезависимую память NVS Flash.
6. **Экран 6: Сервисный экран (Settings & Info):**
   - Статус CAN-шины MegaSquirt, Bluetooth LE, GPS и версия системы.

## 5. Подключение и мобильное приложение (PWA & BLE)

Для управления со смартфона используется **Bluetooth Low Energy (Nordic UART Service)**:
* **Имя устройства в эфире:** `BMW-E36-OBC`

### Управление через веб-приложение PWA:
1. Откройте `index.html` (или `ble_app.html`) в браузере **Google Chrome** / **Microsoft Edge** (Android / ПК) или **Bluefy** (iPhone).
2. Приложение работает полностью автономно (оффлайн через Service Worker) и поддерживает установку на рабочий стол как нативное приложение (кнопка *"Установить приложение на телефон"*).
3. Доступны:
   - Синхронизация времени в 1 клик с телефоном.
   - Живые приборы телеметрии MS2 (Обороты, Наддув, ОЖ, Смесь, Напряжение, Скорость, Расход).
   - Настройка порогов безопасности (варнингов) с сохранением в Flash-память.
   - Переключение экранов и выбор датчика для кругового прибора.

### Сопряжение (защита Bluetooth):
По умолчанию (`BLE_PAIRING_ENABLED 1`) все характеристики зашифрованы. При первом подключении телефон/ПК попросит PIN — это `BLE_PASSKEY` из `config.h` (смените `123456` на свой). Если ваш браузер не показывает запрос PIN и выдает ошибку доступа, поставьте `BLE_PAIRING_ENABLED 0`. Чтобы забыть сопряжение, удалите устройство в настройках Bluetooth телефона.

### Постоянное питание и сон:
Плату можно питать постоянно (через понижающий преобразователь с малым током покоя). Через 3 минуты тишины на CAN-шине (зажигание выключено, телефон не подключен) пробег сохраняется, экран гаснет, и ESP32 уходит в глубокий сон. Просыпается по первому сообщению MegaSquirt на CAN (включили зажигание) или по кнопке GPIO 14. Время во сне продолжает идти и уточняется по GPS после пробуждения. Учтите: GPS NEO-7M, если он тоже на постоянном питании, потребляет ~35 мА — около 0.85 А·ч в сутки от АКБ.

### Обновление прошивки по Bluetooth (BLE OTA):
1. Перед первым использованием смените `OTA_PIN` в `config.h` и один раз прошейте плату по USB.
2. Схема разделов должна содержать два OTA-слота (`Default 4MB with spiffs` — по 1.2 МБ на слот; для 8/16 МБ flash лучше `8M with spiffs` / `16M Flash (3MB APP)`). Размер `.bin` должен быть меньше слота.
3. В Arduino IDE: **Скетч → Экспорт бинарного файла**. Берите `E36_watch.ino.bin` (не `.merged.bin` и не `.bootloader.bin`).
4. В приложении подключитесь к `BMW-E36-OBC`, в карточке **«Обновление прошивки»** выберите `.bin`, введите PIN, нажмите **«Залить прошивку»** (~1–3 мин). Не закрывайте страницу до конца.
5. Устройство проверит CRC32 и SHA-256 образа и перезагрузится. Автоматического отката нет: в стандартном ядре Arduino ESP32 (проверено на 3.3.12) загрузчик собран без APP_ROLLBACK, поэтому прошивку, которая падает при старте, придется перешивать по USB. Перед OTA проверяйте прошивку на столе.

Протокол: сервис `c0de0001-…`, характеристика CTRL `c0de0002-…` (`begin <size> <crc32hex> <pin>`, `end`, `abort`, `ver`; ответы notify), DATA `c0de0003-…` (блоки прошивки, запись с подтверждением).

### Текстовые команды (Serial Bluetooth Terminal):
- `screen 1-6` - выбор экрана
- `gauge <boost|clt|afr|fuel|speed|iat|rpm>` - выбор датчика кругового прибора
- `nextgauge` - переключение на следующий датчик прибора
- `getwarn` - чтение порогов варнингов в формате JSON
- `setwarn [clt|boost|afrmin|afrmax|en] <val>` - настройка порогов
- `resettrip` - сброс суточного пробега
- `epoch <timestamp>` / `time HH:MM:SS` / `date DD.MM.YYYY` / `tz <-12..14>` - настройка времени
- `setodo <км>` - установка общего пробега
- `status` - вывод полной телеметрии ЭБУ
- `sleep` - немедленный переход в глубокий сон

Длинные ответы приходят несколькими уведомлениями; каждое сообщение заканчивается переводом строки.

### Команды через USB (монитор порта 115200):
`n` следующий экран, `g` следующий датчик, `h` удержание кнопки, `r` сброс трипа, `t` тест цветов, `1`–`6` экран, `s` глубокий сон, `q` перезагрузка.
