# BMW E36 On-Board Computer & Clock (ESP32-S3 + GMT024-08 ST7789)

Проект стилизованных цифровых часов и бортового компьютера в штатное место консоли BMW E36 (1991) с аутентичным янтарным стилем подсветки **BMW Amber**, поддержкой замера бортсети, секундомера M-Performance, автосинхронизации времени по Wi-Fi NTP и управления со смартфона.

---

## 1. Аппаратная часть (Распиновка подключения)

### Дисплей GMT024-08 (ST7789 SPI TFT 2.4" 240x320) к ESP32-S3:

| Пин дисплея | Пин ESP32-S3 | Назначение |
|---|---|---|
| **VCC** | 3.3V | Питание дисплея |
| **GND** | GND | Земля |
| **SCL** | **GPIO 13** | SPI Clock (SCK) |
| **SDA** | **GPIO 12** | SPI Data / MOSI |
| **RES / RST** | **GPIO 11** | Сброс дисплея |
| **DC** | **GPIO 10** | Выбор Режим/Команда |
| **CS** | **GPIO 9** | Chip Select |
| **BLK / BL** | **GPIO 8** | Подсветка (ШИМ регулировка яркости) |

### CAN-трансивер WCMCU-230 (SN65HVD230) к MegaSquirt 2:

| Пин трансивера | Пин ESP32-S3 / Авто | Описание |
|---|---|---|
| **3V3** | **3.3V** | Питание логики трансивера от силовой шины 3.3V |
| **GND** | **GND** | Общий провод (земля) |
| **CTX** | **GPIO 6** | Вход данных CAN (TWAI TX) |
| **CRX** | **GPIO 7** | Выход данных CAN (TWAI RX) |
| **CANH** | К проводу **CAN_H** | Шина данных к блоку MegaSquirt 2 |
| **CANL** | К проводу **CAN_L** | Шина данных к блоку MegaSquirt 2 |

> [!IMPORTANT]
> Обратите внимание: линии данных подключаются **напрямую**, а не крест-накрест (**CTX $\rightarrow$ GPIO 6**, **CRX $\rightarrow$ GPIO 7**).

### GPS-модуль u-blox NEO-7M к ESP32-S3:

| Пин NEO-7M | Пин ESP32-S3 | Описание |
|---|---|---|
| **VCC** | **3.3V** или **5V** | Питание модуля |
| **GND** | **GND** | Общая земля |
| **TX** | **GPIO 44 (RX)** | Выход NMEA данных GPS в ESP32 |
| **RX** | **GPIO 43 (TX)** | Вход команд GPS из ESP32 |

### Дополнительные подключения:
* **GPIO 14:** Физическая кнопка переключения экранов (короткий клик — смена экрана / таймер; удержание — сброс суточного одометра TRIP).
* **GPIO 16:** Вход сигнала габаритов/фар (ночной режим).

## 2. Настройка в программе TunerStudio (MegaSquirt 2)

Чтобы ЭБУ отдавал данные в приборную панель по CAN:
1. Откройте ваш проект в **TunerStudio MS**.
2. Перейдите в меню **CAN-bus / Testmodes $\rightarrow$ CAN Parameters**:
   - **Master Enable:** установите в **Enable (On)**.
3. Перейдите в меню **CAN-bus / Testmodes $\rightarrow$ Dash Broadcasting** (или *CAN Realtime Data Broadcasting*):
   - **Enable:** установите в **On**.
   - **Baud Rate:** **500k** (500 kbit/s).
   - **Configuration:** **Automatic** (базовый ID 1512/1520).
4. Нажмите кнопку **Burn** для сохранения в память ЭБУ.

## 2. Инструкция по сборке в Arduino IDE

### Шаг 1: Установка библиотек
В Arduino IDE перейдите в меню **Скетч $\rightarrow$ Подключить библиотеку $\rightarrow$ Управлять библиотеками...** и установите:
1. **`Adafruit GFX Library`** (от Adafruit)
2. **`Adafruit ST7789 and ST7735 Library`** (от Adafruit)
*(При предложении установить зависимые библиотеки нажмите "Install All")*

### Шаг 2: Настройки платы в Arduino IDE
В меню **Инструменты (Tools)** выберите:
- **Плата (Board):** `ESP32S3 Dev Module`
- **USB CDC On Boot:** `Enabled` (если используете прямой USB порт ESP32-S3)
- **Flash Size:** `4MB` (или `8MB`/`16MB` в зависимости от модуля)
- **Partition Scheme:** `Default 4MB with spiffs`

### Шаг 3: Загрузка
Откройте файл `E36_watch.ino` и нажмите кнопку **Загрузка (Upload)**.

## 3. Режимы работы и экраны (UI)

1. **Заставка при включении (Boot Splash):**
   - Лаконичная белая надпись **`Megasquirt 2`** и статус `CAN-BUS TELEMETRY` на чистом черном фоне.
2. **Экран часов и телеметрии (Minimalist Digital Clock):**
   - Крупные белые жирные наклонные цифры времени (`HH:MM:SS`) с мигающим наклонным двоеточием.
   - Нижняя строка оперативной телеметрии из ЭБУ: **`BOOST`**, **`COOLANT`**, **`LAMBDA`**.
3. **Бортовой компьютер (OBC Telemetry):**
   - Координатная сетка: Напряжение АКБ, Температура ОЖ/Впуска, Состав смеси (AFR), Дроссель (TPS), шкала наддува.
4. **Спортивный тахометр ///M Performance:**
   - Крупные обороты мотора (`RPM`), прогрессивный Shift-Light бар, давление наддува и УОЗ.
5. **Сервисный экран (Settings & BLE):**
   - Статус приема CAN пакетов, статус Bluetooth LE, MAC-адрес и системные параметры.

## 4. Подключение и настройка по Bluetooth Low Energy (BLE)

Для управления со смартфона без разрыва мобильного интернета используется **Bluetooth LE (Nordic UART Service)**:
* **Имя устройства в эфире:** `BMW-E36-OBC`

### Управление через Web Bluetooth (без установки программ):
1. Откройте файл [`ble_app.html`](file:///c:/Users/JZX/Documents/Arduino/E36_watch/ble_app.html) в браузере **Google Chrome** или **Microsoft Edge** (на Android, ПК или Mac) или приложении **Bluefy** (на iPhone).
2. Нажмите кнопку **"Подключиться к BMW E36"** и выберите устройство.
3. Доступны:
   - Синхронизация времени в 1 клик с телефона.
   - Регулировка яркости экрана ползунком.
   - Живые приборы телеметрии MS2 (Обороты, Наддув, ОЖ, Смесь, Напряжение).
   - Дистанционное переключение экранов.

### Управление через мобильные терминалы (Serial Bluetooth Terminal):
* Поддерживаются простые текстовые команды:
  - `epoch <timestamp>` — синхронизация точного времени
  - `time HH:MM:SS` — ручная установка часов
  - `date DD.MM.YYYY` — ручная установка даты
  - `bright 0-255` — настройка яркости
  - `screen 0-3` — смена экрана
  - `status` — вывод полной телеметрии ЭБУ
